# Definition of Done

- [ ] Feature branch created from `main` and a pull request opened
- [ ] All acceptance criteria for the story are met
- [ ] Tests are written and passing locally
- [ ] CI pipeline runs green on the pull request
- [ ] No known bugs or open defects for the story
- [ ] Commits are small with conventional messages (e.g. `test(US1): ...`, `feat(US1): ...`)
- [ ] Documentation (README, API docs, plan) is updated if needed
- [ ] The story is shown and demoed in the Sprint Review
